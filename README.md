# Three.js 从入门到实战

一本依据 **Three.js Journey** 课程整理的中文技术电子书。全书按知识主题重组为 **6 个部分、45 章，另加后记**，涵盖 WebGL、Three.js、GLSL、Blender 与 React Three Fiber。

## 在线阅读

**[https://zhaojiew10.github.io/threejs-journey-ebook/](https://zhaojiew10.github.io/threejs-journey-ebook/)**

网站提供完整章节目录、站内搜索、代码高亮、课程画面与 SVG 原理示意图，适合按顺序学习或按主题查阅。

## 本书内容

### 第一部分 · Three.js 基础（第 1—8 章）

从 WebGL 的基本定位开始，完成开发环境搭建，并掌握场景、网格、变换、动画、相机、几何体、纹理、材质与项目部署等基础知识。

### 第二部分 · 经典渲染技术（第 9—16 章）

围绕灯光、阴影、粒子、物理、模型、环境贴图和写实渲染构建完整场景，并通过综合练习理解各项技术如何协同工作。

### 第三部分 · 工程化与 GLSL 着色器（第 17—30 章）

先建立可持续扩展的项目结构，再系统学习 GLSL、材质定制、粒子与 GPGPU，将渲染控制延伸到 GPU 着色阶段。

### 第四部分 · 后期处理与交互体验（第 31—32 章）

介绍后期处理链、性能诊断、加载过程以及 HTML 与 WebGL 的协同方式，兼顾视觉质量、运行效率和使用体验。

### 第五部分 · Blender 场景工作流（第 33—35 章）

贯通 Blender 建模、烘焙、导出和 Three.js 导入优化流程，将 DCC 工具制作的场景转化为可交互的网页体验。

### 第六部分 · React Three Fiber（第 36—45 章）

从 React 与 R3F 的基础开始，逐步学习 Drei、模型、事件、后期处理和物理系统，最终完成作品集与游戏项目。

## 内容特点

- 将口语字幕重构为书面中文，而不是逐句拼接转写。
- 按知识关系合并课程，例如“对象变换与动画”“灯光与阴影”“环境贴图与写实渲染”。
- 结合中英文字幕及课程书面资料校正 Three.js、WebGL、Vite、GLSL 等专业术语。
- 正文不含字幕时间戳；每章配置课程画面，概念章节另配 SVG 示意图。
- 保留核心 API、必要代码、操作顺序、参数含义和常见问题。

## 推荐阅读方式

- **系统学习**：按章节顺序阅读，前面的场景、材质、动画和渲染知识会在后续项目中反复使用。
- **关注 GLSL**：在掌握 Three.js 基础后，从第 18 章开始学习，再进入各着色器项目。
- **关注工程化与性能**：阅读第 17 章的项目架构，以及第 31 章的后期处理和性能优化。
- **关注 React Three Fiber**：具备 React 基础后可阅读第六部分；不熟悉 React 时，建议先完成第 37 章。
- **边读边实践**：运行书中代码并修改参数，观察渲染结果。着色器和性能相关内容尤其需要实际验证。
